# Job descriptions for Chapter 28

Chapter 28 (Bangladesh-focused job preparation) must be based on real evidence, not
guesses. Job sites often block automated browsing, so the most reliable evidence is the
job descriptions you collect yourself.

## How to add one

1. Copy the full text of a job posting (from bdjobs.com, LinkedIn, a company's own careers
   page, or a university job board) into a new `.md` or `.txt` file in this folder.
2. Put these lines at the top of the file:

   ```
   Source URL: <link to the posting>
   Company: <company name>
   Role: <job title>
   Date accessed: <YYYY-MM-DD>
   ```

3. Name the file `YYYY-MM-DD-company-role.md`, for example
   `2026-10-20-example-co-junior-java-developer.md`.

10–20 postings for the roles you actually want are enough for a useful analysis. Remove
personal data such as recruiter phone numbers or email addresses before saving.
